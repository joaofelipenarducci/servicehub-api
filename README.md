ServiceHub API

API REST desenvolvida em Java e Spring Boot para gerenciamento de usuários.

Tecnologias

- Java 21
- Spring Boot
- PostgreSQL
- Docker
- JPA
- Flyway
- Swagger/OpenAPI
- Maven

Funcionalidades

- Criar usuários
- Listar usuários
- Buscar usuário por ID
- Atualizar usuários
- Excluir usuários

Como executar

1. Clone o repositório:

git clone URL_DO_REPOSITORIO

2. Entre na pasta do projeto:

cd servicehub-api

3. Inicie o PostgreSQL pelo Docker.

4. Execute a aplicação pelo IntelliJ ou Maven.

5. A API estará disponível em:

http://localhost:8080

Swagger

Para visualizar e testar os endpoints:

http://localhost:8080/swagger-ui/index.html
